# Datasets

## 1. Built-in: `data/nad_dataset.csv` (ready now ✅)

Generated by `scripts/generate_dataset.py` from this system's own traffic
engine — 6,000 labeled flows, 41 CIC-IDS style features + `label` + `attack_type`.

| Label | Flows |
|---|---|
| Normal | 4,020 |
| SYN Flood / UDP Flood / SSH Brute Force / DNS Tunneling / Port Scan / SQL Injection / Data Exfiltration | ~283 each (1,980 total) |

```bash
# regenerate (custom size/ratio/seed)
/tmp/nadvenv/bin/python scripts/generate_dataset.py --flows 10000 --attack-ratio 0.3

# train on it
/tmp/nadvenv/bin/python train_model.py --dataset data/nad_dataset.csv --model hybrid
```

Baseline result on this file: precision **1.0**, recall **0.17** @0.5 —
conservative (zero false positives, misses subtle cases). Tune
`NAD_ANOMALY_THRESHOLD` / retrain per [CONFIGURATION](CONFIGURATION.md).

Use it for: smoke-training the pipeline, threshold experiments, demo
evaluation, and regression checks after model changes.

## 2. Public benchmarks (for serious ML validation)

| Dataset | Contents | Get it |
|---|---|---|
| CICIDS2017 | 5 days of labeled flows + PCAPs (brute force, DoS, web attacks, infiltration) | https://www.unb.ca/cic/datasets/ids-2017.html |
| UNSW-NB15 | 2M+ records, 9 attack families (UNSW Canberra) | https://research.unsw.edu.au/projects/unsw-nb15-dataset |
| NSL-KDD | Cleaned KDD'99 classic, train/test split | via https://www.unb.ca/cic/datasets/ (CIC dataset index) |

To use one here: export the flows to CSV with numeric feature columns plus a
`label` column (`Normal` vs attack name), then run
`train_model.py --dataset <file>`. The loader auto-aligns column counts to the
41-feature vector and reports precision/recall/F1 at thresholds 0.5 and 0.7.

## 3. Roll your own (lab captures)

```bash
tcpdump -i eth0 -w lab.pcap          # capture on your own network only
# label flows with Wireshark/tshark, export CSV, train as above
```

Keep one `lab-*.pcap` per scenario (scan day, flood day, quiet day) —
replaying them after detector/threshold changes is your regression suite
(see [TESTING](TESTING.md)).
